API REST del TPV

JSON sobre HTTP, conectada a la base de datos apitpvrestaurante de MySQL/MariaDB. Todas las rutas cuelgan de la URL base:

Si mod_rewrite está activo también funciona sin index.php (/api/platos/3). Los cuerpos se envían como application/json.

Autenticación

La API usa una sesión de PHP (cookie tpv_sesion). Inicia sesión con POST /auth/login y envía la cookie en las siguientes peticiones. Las contraseñas se guardan cifradas con bcrypt.

Público
No necesita sesión.
Sesión
Cualquier empleado con sesión iniciada.
Carta
admin, gerente o jefe de cocina.
Sala
admin, gerente o jefe de sala.
Dirección
admin o gerente.

Errores

Los errores devuelven un código HTTP y un cuerpo {"error": "mensaje"}.

400JSON o identificador mal formado.
401Falta iniciar sesión o la contraseña es incorrecta.
403El rango del empleado no permite la acción.
404El recurso o la ruta no existen.
409Conflicto: nombre duplicado, registro en uso, mesa ocupada o cambio de estado no permitido.
422Faltan campos o tienen un valor no válido.
